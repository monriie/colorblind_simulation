# Machado Red-Green Color Vision Deficiency Fruit Image Dataset

## About Dataset

This dataset contains prepared fruit images selected for protan and deutan color-confusion analysis, together with their simulated versions generated using the Machado color vision deficiency model. It is intended for research and education about model-based color transformations. The model was applied to the images; it was not trained on this dataset.

## Dataset Description

The source images come from the training subset of Hulin Kuang's *Fruitdataset* (2015). The preparation process started with 4,870 images from 19 fruit classes and excluded the background class `000neg`. Within-class perceptual-hash deduplication removed 178 duplicate images. The remaining 4,692 images were center-cropped to a square and resized to 512 × 512 pixels.

Color analysis sampled 1,000 pixels from each complete image, including its background. Four K-means clusters represented the sampled colors. Pairwise color distances to the protan and deutan confusion lines were calculated in the CIE 1931 chromaticity diagram. Otsu-derived distance thresholds and class-level filtering were used to select images. The resulting thresholds were 0.06644655 for protan and 0.07713304 for deutan. These are operational thresholds for this dataset, not clinical cutoffs.

Undersampling and final group balancing produced 456 image-family selections for each CVD type. The two groups contain 782 unique source images in total because 130 images were selected for both types. The protan selection contains 9 fruit classes and the deutan selection contains 8; 7 classes are shared, making 10 classes across their union.

Each selected image was simulated at four severity settings: 0.25, 0.50, 0.75, and 1.00. The release contains 3,648 simulated PNG images. Severity 1.00 is the dichromacy endpoint in the Machado model. Severity values are model parameters and should not be interpreted as clinical diagnoses or percentages of visual loss.

`confusion_line_filtered/` contains 456 prepared source images per type. An image selected for both types appears in both folders. Each type/severity folder under `simulated_images/` contains 456 images at 512 × 512 pixels. Filenames identify the fruit class and source image identifier, for example `apple_109.png`.

Optional summary files can include `confusion_line_class_summary.csv`, `confusion_line_filter_summary.csv`, `simulation_group_summary.csv`, `evaluation_group_summary.csv`, `evaluation_paired_summary.csv`, and `evaluation_paired_difference_summary.csv`. Do not publish per-image reports with local absolute file paths; remove those columns or convert them to relative paths first.

## Data Processing and Simulation

The source images were deduplicated within each class, center-cropped, and resized. No foreground segmentation was applied. Consequently, background pixels are included in color sampling, selection, and evaluation.

For simulation, sRGB values were decoded to linear RGB, transformed with the Machado matrices for the selected CVD type and severity, clipped to the sRGB gamut, encoded back to sRGB, and saved as 8-bit PNG images.

## Evaluation Summary

CIEDE2000 was calculated between corresponding pixels in each original/simulated image pair after conversion to CIELAB. The image-level value is the mean across the complete image, including its background. The overall mean across 3,648 evaluations was 9.0244.

| CVD type | Severity | Images | Mean ΔE00 |
| --- | ---: | ---: | ---: |
| Deutan | 0.25 | 456 | 4.2221 |
| Deutan | 0.50 | 456 | 7.5620 |
| Deutan | 0.75 | 456 | 10.1270 |
| Deutan | 1.00 | 456 | 12.1769 |
| Protan | 0.25 | 456 | 4.1950 |
| Protan | 0.50 | 456 | 7.8448 |
| Protan | 0.75 | 456 | 11.2274 |
| Protan | 1.00 | 456 | 14.8398 |

Both group means increase with severity. Deutan is slightly higher at severity 0.25, while protan is higher from 0.50 through 1.00. These are descriptive results from separately selected groups with different class compositions. A paired analysis of the 130 shared source images is available in the optional evaluation files.

## Intended Use and Limitations

The images can support research, teaching, and inspection of color transformations generated by the specified model. They do not constitute a clinical dataset or a direct measure of how all people with protan or deutan conditions perceive the images. No participants with CVD were involved in this evaluation.

Because there is no foreground segmentation, background color can influence both image selection and CIEDE2000 measurements. Equal image counts do not mean that the protan and deutan groups have identical class composition. Results apply to the selected Fruitdataset images and the stated model settings only.
