# Machado Red-Green Color Vision Deficiency Fruit Image Dataset

## Dataset Description

This dataset provides prepared fruit images selected for protan and deutan color-confusion analysis, along with images simulated using the Machado color vision deficiency model. It is intended for research and education about model-based color transformations. The model was applied to the images; it was not trained on this dataset.

The source images are from the training subset of Hulin Kuang's *Fruitdataset* (2015). The preparation process began with 4,870 images in 19 fruit classes, excluding the background class `000neg`. Within-class perceptual-hash deduplication removed 178 duplicates, leaving 4,692 images. Each was center-cropped to a square and resized to 512 × 512 pixels.

For color analysis, 1,000 pixels were sampled from each complete image, including its background, and summarized with four K-means clusters. Pairwise color distances to protan and deutan confusion lines in the CIE 1931 chromaticity diagram were used with Otsu-derived thresholds and class-level filtering. The thresholds were 0.06644655 for protan and 0.07713304 for deutan. These are operational settings for this dataset, not clinical criteria.

Final undersampling and group balancing yielded 456 selected image-family memberships per type, or 782 unique source images because 130 images occur in both groups. The protan group has 9 classes, the deutan group has 8, and their union has 10 classes. Each selected image was simulated at severities 0.25, 0.50, 0.75, and 1.00, resulting in 3,648 simulated PNG images. Severity 1.00 is the dichromacy endpoint in the model; severity values are not clinical diagnoses or percentages of visual loss.

## Data Processing

Images were deduplicated within each fruit class and center-cropped/resized. The workflow did not use foreground segmentation. Thus, background pixels are included in color sampling, selection, and evaluation. The selected cohorts are based on the measured color distances and the operational thresholds described above.

## Simulation

Each selected sRGB image was decoded to linear RGB, transformed using the Machado matrices for the assigned CVD type and severity, clipped to the sRGB gamut, encoded back to sRGB, and saved as an 8-bit PNG image.

## Evaluation

CIEDE2000 was calculated for corresponding pixels after conversion to CIELAB. Each image-level score is the mean across all pixels in the image, including its background. The overall mean across 3,648 evaluations is 9.0244.

| CVD type | Severity | Image count | Mean ΔE00 |
| --- | ---: | ---: | ---: |
| Deutan | 0.25 | 456 | 4.2221 |
| Deutan | 0.50 | 456 | 7.5620 |
| Deutan | 0.75 | 456 | 10.1270 |
| Deutan | 1.00 | 456 | 12.1769 |
| Protan | 0.25 | 456 | 4.1950 |
| Protan | 0.50 | 456 | 7.8448 |
| Protan | 0.75 | 456 | 11.2274 |
| Protan | 1.00 | 456 | 14.8398 |

Both group means rise with severity. Deutan is slightly higher at 0.25, while protan is higher from 0.50 to 1.00. These are descriptive group results; the groups have equal sizes but different class compositions. A separate paired analysis covers the 130 source images selected for both types.

## Intended Use and Limitations

The dataset is intended for research, teaching, and inspection of color transformations generated by the specified model. It is not a clinical dataset and does not directly validate CVD perception. No participants with CVD were included in the evaluation. Since no foreground segmentation was applied, background colors can affect image selection and CIEDE2000 results. Findings apply only to these selected images and model settings.
